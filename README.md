# Sales Performance Dashboard (Excel)

## Overview
This project analyzes sales data using Excel to generate business insights through an interactive dashboard.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers

## Features
- Sales analysis by region, product, and time
- Interactive filtering using slicers
- Key performance indicators (KPIs)
- Visual dashboards for decision-making

## Key Insights
- Nairobi recorded the highest sales performance
- Technology products outperform furniture
- March shows strong sales activity
